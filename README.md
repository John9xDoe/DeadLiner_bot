# DeadLiner Bot 🤖

A Telegram bot for managing tasks with deadlines: creation, reminders, and status tracking. This project demonstrates a rapid MVP development approach using AI-assisted coding, followed by iterative refinement and stabilization.

---

## 🚀 Features

DeadLiner Bot allows users to:

* create tasks with deadlines
* receive reminders
* track task status
* manage tasks via a Telegram interface

The project is designed for **automating routine workflows** and can be adapted for various use cases (personal productivity, team workflows, marketing processes).

---

## 🧠 Development Approach

This project was built with active use of AI development tools:

* generating initial code structure and logic
* accelerating implementation through prompt-based iteration
* refining solutions based on real usage scenarios

Post-generation improvements included:

* handling edge cases
* simplifying and stabilizing logic
* adapting flows for better UX

## 📦 Quick Start

```bash
git clone <your-repo-link>
cd deadliner-bot
pip install -r requirements.txt
```

Create a `.env` file:

```
BOT_TOKEN=your_telegram_token
```

Run the bot:

```bash
python main.py
```
